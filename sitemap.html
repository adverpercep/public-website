Asset Needed Open Graph (OG) Share Image

When any page on this site is shared on LinkedIn, Slack, iMessage, or in an email, platforms display a preview image alongside the link. That image is the OG image. All 22 pages are already coded to use it — the image file just needs to be created and uploaded to the exact path below.

Dimensions1200 × 630 px
FormatJPG or PNG
File sizeUnder 1 MB
Pages using itAll 22 pages
1Design a branded graphic — AP logo on navy background, company name, optional tagline. Canvas size: 1200 × 630 px.
2Export as PNG or JPG, under 1 MB.
3Upload to WordPress Media Library and save with this exact filename (already wired into every page):
https://www.advertiserperceptions.com/wp-content/uploads/2026/06/ap-og-image.png

If the uploaded path differs, the URL in each page's <head> can be batch-updated to match.
